The Planton operator is installed. It deploys nothing until you apply a
PlantonPlatform resource -- the minimal one is three lines:

  kubectl apply -f - <<EOF
  apiVersion: planton.ai/v1
  kind: PlantonPlatform
  metadata:
    name: planton
    namespace: {{ .Release.Namespace }}
  spec:
    version: {{ .Chart.AppVersion }}
  EOF

  kubectl get plantonplatform planton -n {{ .Release.Namespace }} -w

Prefer the platform as a Helm release with proven defaults and per-cloud
values files? The `planton` chart declares it:

  helm install planton oci://ghcr.io/plantonhq/charts/planton -n {{ .Release.Namespace }}

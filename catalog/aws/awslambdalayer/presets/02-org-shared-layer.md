# Organization-Shared Runtime Layer

A platform team's layer published for the whole AWS Organization: the wildcard principal scoped down by `organizationId` lets every member account attach it, and `skipDestroy` keeps replaced versions alive so consumer functions never break mid-rollout. Substitute the `o-replaceme0000` placeholder with your organization's real `o-...` id from the AWS Organizations console — the preset ships it in the valid lowercase format the spec enforces. `sourceCodeHash` is omitted on purpose: without it a new version publishes whenever the S3 key or object version changes, which is the right starter behavior; pipelines that want content-addressed republishes set it to `base64(sha256(zip))` at build time.

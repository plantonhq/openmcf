### 3. Protobuf API Definitions — validation quality note

`GcpCloudComposerDataRetentionConfig` carries a `retention_days_require_mode` message CEL: `airflow_metadata_retention_days` requires `airflow_metadata_retention_mode` to be set — the API silently ignores a bare day count, so it is rejected pre-deploy. Exercised by the 67-case spec test ("reject airflow_metadata_retention_days without a retention mode").

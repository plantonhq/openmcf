### Protobuf API Definitions — validation quality note

The spec models the vector-search serving surface at the released 6.50.0
floor: ambient-optional `project_id` ref, immutable `location`, mutable
`display_name`/`description`/`labels`, and three mutually exclusive,
individually immutable connectivity arms — `public_endpoint_enabled`,
VPC-peered `network` (→ GcpVpcNetwork ref), and
`private_service_connect_config` (`enable_private_service_connect` +
`project_allowlist`). Three message-level CEL rules make the arms
pairwise exclusive pre-deploy (the provider rejects the combinations only
at create), and a field-level CEL pins `enable_private_service_connect`
to `true` when the PSC block is present — the API's own enablement
contract, modeled explicitly rather than inferred from block presence.
The docs and spec explicitly distinguish this kind from the
online-prediction `GcpVertexAiEndpoint` (671) — different GCP resources,
correctly different kinds. 23-case spec test, all green, covering every
CEL rule positive + negative (the spec surface is genuinely smaller than
its siblings; coverage is complete, not thin).

### The peered-network normalization — the live-only rejection class, guarded

The Vertex AI API expects the RELATIVE network form
`projects/{project}/global/networks/{name}`, while the GcpVpcNetwork
reference's canonical output is a compute self-link URL. Both engines
normalize the self-link to the relative form IDENTICALLY (the session-022
SCP normalization precedent): Pulumi via `strings.TrimPrefix` of the
`https://www.googleapis.com/compute/v1/` prefix, Terraform via the
equivalent anchored-regex `replace()` — byte-for-byte equivalent,
no-ops on already-relative values. This guards the AlloyDB/Filestore
class of live-only rejections even though the peered arm itself is an
offline-proven exclusion.

**Parity verdict: PARITY ✅**

  (`disable_on_destroy=false`) and gate the endpoint on it.

  set wins on conflict; key set verified identical across engines.

  `index_endpoint_name` (numeric), `public_endpoint_domain_name`
  (populated only on the public arm), `create_time`, `update_time`.

### Composition contract

`index_endpoint_id` is exactly the value
`GcpVertexAiDeployedIndex.spec.index_endpoint` consumes via `default_kind`
FK wiring. The `network` ref defaults to
`GcpVpcNetwork.status.outputs.network_self_link` with regional overrides
possible via explicit `valueFrom.kind`.

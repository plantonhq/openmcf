## Parity Notes

- Validation location differs by engine necessity (TF: variable `validation`
  blocks at plan; Pulumi: Go checks before the resource call) but the contract
  is byte-identical: same regex, same deleted-principal rejection. Not a
  divergence — both fail before any API call with equivalent messages.
- Authoritative binding/policy modes deliberately unmodeled (clobber semantics
  are hostile to composition); recorded in `docs/README.md`.
- No `PARITY-EXCEPTION` markers needed.

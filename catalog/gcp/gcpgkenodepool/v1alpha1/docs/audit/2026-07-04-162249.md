Defects fixed relative to the prior implementation (all verified against the released
google 6.50.0 schema dump):

- **Cluster-resolution parity break** — the TF module discovered the cluster via a
  `google_container_cluster` data source with `location = "*"` while Pulumi used the spec
  field. Both engines now consume the same `cluster_name` + `location` references
  (resolved from the cluster's outputs).
- **FK contract defect** — `cluster_project_id` resolved from the cluster's
  `spec.project_id` (legitimately empty for ambient-project clusters). Replaced by
  `project_id` → GcpProject with the ambient fallback, and `location` → the cluster's
  `location` output.
- **Pulumi spot/preemptible conflation** — one spec flag set BOTH provider fields; they
  are distinct capacity models, now separate fields with a not-both CEL.
- **Hardcoded opinions removed** — `upgrade_settings{max_surge=2}`, the fixed 3-scope
  `oauth_scopes` list, the `gke-<cluster>` network tag, and dead label plumbing.
- **Negative booleans** (`disable_auto_upgrade`/`disable_auto_repair`) → positive
  `auto_repair`/`auto_upgrade` defaulting true (GKE's own defaults).
- **Stale shapes** — `object({value})` ref typing in variables.tf, hardcoded `6.19.0`
  pin → `~> 6.0`, stale commented `binary:` in Pulumi.yaml, legacy `hack/manifest.yaml`
  beside canonical `iac/hack/` — all cleared.

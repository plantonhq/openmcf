### 5b. Cross-Engine IaC Parity (Critical GATE)

**Parity verdict: PARITY ✅**

Compared engines: Pulumi (`iac/pulumi/module/`) and Terraform (`iac/tf/`), both judged against `spec.proto` + `stack_outputs.proto` (neither privileged). Output parity verified with the automated guards, not by eye: `planton validate-outputs --kind AzureNetworkInterface --module-dir .../iac/tf --sample-outputs <sample>.json` → **6/6 proto fields populated, zero unmapped**, and the per-kind `pkg/outputs/conformance_test.go` case (`AzureNetworkInterface`, all 6 fields in `mustPopulate`) passes fresh.

| Dimension | Pulumi | Terraform | Verdict |

| Region / edge zone | `spec.region`, `spec.edge_zone` (omit-when-empty) | same fields (null-when-unset) | ✅ MATCH |

| dns_servers / internal_dns_name_label | omit-when-empty | `optional(..., [])` / null | ✅ MATCH |

| Stack outputs → proto | 6 exports via `outputs.go` constants | 6 identically named outputs | ✅ MATCH (validate-outputs: 6/6) |

**Legend:** ✅ MATCH | ⚠️ DIVERGES (undocumented) | 🔵 EXCEPTION (documented `PARITY-EXCEPTION:`)

✅ **In parity:**

- All 14 top-level spec fields and all 8 `ip_configurations` sub-fields (`name`, `subnet_id`, `private_ip_allocation`, `private_ip_address`, `private_ip_version`, `public_ip_address_id`, `primary`, `gateway_load_balancer_frontend_ip_configuration_id`) are honored by both engines with identical ARM values.
- Unset-enum handling is behaviorally identical: unspecified allocation/version resolve to Azure's defaults (`Dynamic`, `IPv4`) on both engines, and the unspecified auxiliary mode/SKU send nothing on both (the non-appliance default) — Pulumi's empty-string guard ↔ Terraform's null ternary.
- Both engines realize the NIC-level NSG and each ASG membership as separate association resources (Azure's own ARM model), created only when the spec declares them, with the implicit dependency edge on the NIC's ID on both sides.
- Both output sets flatten onto the same six `AzureNetworkInterfaceStackOutputs` fields, including the repeated `private_ip_addresses` (mapped via the generic reflection transformer, no per-kind override needed).

🔵 **Documented exception:**

- **Tag shape (family-wide).** Terraform emits the snake-case `resource_kind = "azure_network_interface"` literal and falls back `resource_id → metadata.name`; Pulumi emits the lowered `CloudResourceKind` enum string and omits `resource_id` when `metadata.id` is empty. A `PARITY-EXCEPTION:` comment is present in **both** modules (`iac/tf/locals.tf` lines 8-13 and `iac/pulumi/module/locals.go` lines 69-75), the divergence is output-neutral (tags never feed stack outputs), and it is flagged as a family-wide convention change rather than a per-kind fix. This is the known documented item and is NOT a defect.

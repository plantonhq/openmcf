## Apply-Time Validator Source-Diff

Read `private_endpoint_resource.go` schema + CustomizeDiff + create path:

- **id XOR alias** (ExactlyOneOf on the connection block): front-loaded
  as the `connection_target_exactly_one` message CEL.
- **manual-connection / request_message pairing** (CustomizeDiff enforces
  BOTH directions -- message requires manual, manual requires message):
  front-loaded as the `manual_connection_request_message_pairing` CEL,
  both directions in one expression.
- **request_message 1-140** (StringLenBetween): the length cap is a field
  CEL; the non-empty half is subsumed by the pairing CEL.
- **alias suffix** (`validate.PrivateConnectionResourceAlias` requires
  `.azure.privatelinkservice`; also re-checked in the create path via
  `validatePrivateLinkServiceId`): front-loaded as the
  `connection_alias_suffix` field CEL.
- **PrivateLinkName** (1-80, begin letter/number, end letter/number/
  underscore): front-loaded as the `private_endpoint_name_format` CEL.
- **ip_configuration member_name O+C** (Azure errors when a member id is
  sent where none is expected -- the provider's own comment): modeled as
  optional and sent only when set on both engines.
- No spec CEL invents a rule the provider and ARM do not enforce.

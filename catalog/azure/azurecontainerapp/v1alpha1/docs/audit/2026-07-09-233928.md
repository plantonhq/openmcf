resource group FK, environment FK, revision mode enum, workload profile,
max_inactive_revisions, tags), the complete template (containers with per-type
probes/env/mounts, init containers, 4-value volume vocabulary

identity. Computed outputs all exported; `custom_domain_verification_id`
carries `sensitive = true` in the TF output (provider-Sensitive attribute).

## Parity

maps (revision mode, probe transports, ingress transports, client cert modes,

(replica bounds, cooldown/polling, grace period, probe dials). The prior
ingress asymmetry (TF cors-only / Pulumi cert-mode-only) is closed. Only the
family-wide tag-shape PARITY-EXCEPTION remains (output-neutral, documented).

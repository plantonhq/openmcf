**Parity verdict: PARITY ⚠️**

Compared engines: Pulumi (`iac/pulumi/module/`) and Terraform (`iac/tf/`), both judged
against the proto contract (`spec.proto` + `stack_outputs.proto`) and intended behavior
(neither engine privileged). Stack outputs verified with the automated guard, not by eye:
`go run . validate-outputs --kind AzurePublicIp --module-dir .../iac/tf --sample-outputs <sample>.json`
→ **4/4 proto fields populated, zero unmapped**. A per-kind case exists in
`pkg/outputs/conformance_test.go` (`AzurePublicIp`, exercising all four outputs) and
`go test ./pkg/outputs/` passes.

**Legend:** ✅ MATCH | ⚠️ DIVERGES (undocumented) | 🔵 EXCEPTION (documented `PARITY-EXCEPTION:`)

✅ **In parity:**

- Every `spec.proto` field (all 17) is honored by BOTH engines, including all of this
  session's rework: sku, sku_tier, ip_version enums; domain_name_label_scope; reverse_fqdn;
  ip_tags; public_ip_prefix_id FK; ddos_protection_mode + plan id; edge_zone; user tags;
  allocation hardcoded Static.
- Unspecified-enum handling is identical: neither engine sends a value, so Azure's defaults
  (Standard / Regional / IPv4 / region-unique label / VirtualNetworkInherited DDoS) apply
  identically regardless of provisioner.
- Stack outputs are name-for-name identical and fully populate the proto (automated guard).

⚠️ **Divergences (undocumented):**

- **`resource_kind` tag value** — Pulumi emits `azurepublicip`
  (`strings.ToLower(CloudResourceKind_AzurePublicIp.String())` in `module/locals.go`),
  Terraform emits `azure_public_ip` (literal in `locals.tf`). Impact: **cosmetic** — an Azure
  governance tag value differs by engine; the deployed address, its properties, and all stack
  outputs are identical. Note the same drift pattern exists in the sibling
  `AzureNatGateway` modules, so this is family-wide, not specific to this rework.
  Fix: align one side (the enum-derived value is the convention per `MODULE_PARITY.md`) or
  add a `PARITY-EXCEPTION:` comment in BOTH modules.
- **`resource_id` tag when `metadata.id` is empty** — Pulumi omits the tag entirely;
  Terraform falls back to `metadata.name` so the tag is always present. Impact:
  **cosmetic** (tag presence only). Fix: pick one behavior and mirror it, or document.

**Effect on score:** caps Categories 4 (Pulumi) and 5 (Terraform) at ⚠️ Partial. Neither
divergence would misdeploy (no wrong scope, missing feature, or empty output field), so the
verdict is ⚠️, not ❌.

# IP list

An IP-type Zero Trust list of CIDRs and addresses. Reference `list_id` from a Gateway HTTP or L4 policy `traffic` expression.

## When to Use

- Allowlisting corporate egress CIDRs
- Blocking known-bad addresses shared across several policies
- Device-posture or L4 rules that match source IPs

## Key Configuration Choices

- **type: IP** -- immutable. A DOMAIN list cannot become an IP list in place.
- **CIDR or host** -- both are valid item values. This is not the older Ruleset `CloudflareList` (that family lives under `rules/lists/`).

## Placeholders to Replace

| Placeholder | Description | Where to Find |
|-------------|-------------|---------------|
| `account_id` | The Cloudflare account that owns this list | Cloudflare Dashboard -> Overview -> API section |
| `items[].value` | CIDRs or addresses | Your network inventory |

     exists in sibling Azure kinds, but it is undocumented here.

     engine, or add a `PARITY-EXCEPTION:` comment in BOTH `locals` files.

     Cosmetic, but undocumented.

     whichever matches platform intent — or document the exception in both modules.
   - **Files:** `iac/pulumi/module/locals.go`, `iac/tf/locals.tf`

✅ **In parity:** scope source, naming basis, spec feature coverage (every field honored by
both engines with identical unset semantics), enum→ARM string mapping, tag merge order,
dependency ordering, and stack outputs.

⚠️ **Divergences (undocumented):**

- **`resource_kind` tag value** — Pulumi writes the lowered `CloudResourceKind` enum string
  (`azurepublicipprefix`); Terraform writes an ad-hoc snake-case literal
  (`azure_public_ip_prefix`). Impact: cosmetic — the same Azure resource is deployed either
  way, but the governance tag differs by engine. Note: the identical drift exists in sibling
  Azure kinds (`AzurePublicIp`, `AzureNatGateway`), so a platform-wide alignment decision is
  the right fix, not a one-off.
- **`resource_id` tag presence** — Terraform always emits the tag (falling back to
  `metadata.name`); Pulumi omits it when `metadata.id` is empty. Impact: cosmetic.

**Effect on score:** caps Categories 4 & 5 at Partial (−1.00 and −0.30 respectively). No
divergence would misdeploy, so this is ⚠️ not ❌.

## Apply-Time Validator Source-Diff

Read `container_app_environment_certificate_resource.go` (typed
resource, schema + Create/Update/Read) and
`validate/validate.go#CertificateName`:

- **CertificateName validator** (`^[a-z0-9][a-z0-9-.]*[a-z0-9]$`, no
  trailing hyphen, no `--`) -- front-loaded verbatim as the name CEL.
- **ExactlyOneOf blob/key-vault** and **RequiredWith blob<->password**
  (schema-level) -- the source XOR is a message CEL; the password
  pairing is deliberately one-directional (password requires blob):
  RequiredWith requires the password ARGUMENT with the blob, and both
  engines always send it (possibly empty) alongside the blob --
  an empty-password PFX is legal (the provider's own acceptance
  fixtures include one), so a both-or-neither CEL would have been an
  INVENTED rule rejecting passwordless bundles.
- **Key Vault identity** validates "System" OR a UAI resource id,
  default "System" -- both engines send the explicit "System" fallback.
- **Read never returns the blob** (the provider re-reads it from
  config) -- documented on the spec field and both modules.
- Create is a synchronous PUT (no LRO); only tags update in place --
  documented. No CustomizeDiff.

## Recorded Skips (with reasons)

- **`minimum_tls_version`** -- the provider accepts exactly one value
  (`TLS12`) and hardcodes it at create; a one-value knob is a constant.
  Re-enable trigger: Azure adding a second floor.
- **ARM `deferUpgrade` + writable `port`** -- in the ARM API, in NEITHER
  engine; unshippable until the provider models them.
- **ARM read-backs `redisVersion` / `redundancyMode`** -- not exposed as
  attributes by either engine; cannot be honest outputs.
- **Flush-databases action** -- imperative, not declarative state.
- **Module `version`** -- output-only in the provider.

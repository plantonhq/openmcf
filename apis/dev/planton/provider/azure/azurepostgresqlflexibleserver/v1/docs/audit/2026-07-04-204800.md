## Category 5b: Cross-Engine IaC Parity (the gate this audit leads with)

Field-by-field sweep of `iac/tf/` vs `iac/pulumi/module/` against
`spec.proto` + `stack_outputs.proto`:

- **Resource surface identical**: `azurerm_postgresql_flexible_server` /
  `postgresql.FlexibleServer` plus the four child resources (database,
  firewall rule, configuration, Entra administrator), one per spec entry
  on both engines.
- **Enum vocabularies exhaustive and identical**: create modes
  (`Default`/`PointInTimeRestore`/`Replica`/`GeoRestore`/`ReviveDropped`),
  HA modes, identity types (incl. the `SystemAssigned, UserAssigned`
  compound), principal types, and the 11 storage tiers.
- **Conditional-send behavior identical**: `version` only for fresh
  (DEFAULT) servers (replicas/restores inherit); credentials only when
  non-empty (Entra-only servers and replicas omit them);
  `replication_role` never at create (Azure rejects it — day-2
  promotion only); unspecified create_mode not sent at all.
- **Tenant fallback identical**: the Entra tenant falls back to the
  deploying credential's tenant (`data.azurerm_client_config` /
  `core.GetClientConfig`) for both the auth block and administrator
  grants.
- **Presence-guard sweep clean**: version (16), retention (7), public
  access (true), password_auth (true), charset (UTF8), collation
  (en_US.utf8) — Pulumi falls back explicitly where Terraform's
  `optional(...)` defaults apply.
- **Outputs identical**: `server_id`, `server_name`, `fqdn`,
  `administrator_login`, `database_ids` (name-keyed map),
  `identity_principal_id` (conditionally populated only when the
  identity type includes SYSTEM_ASSIGNED on BOTH engines).
- **Documented exception (family-wide, output-neutral)**: the
  metadata-derived tag shape carries the standing `PARITY-EXCEPTION`
  comment in BOTH modules.

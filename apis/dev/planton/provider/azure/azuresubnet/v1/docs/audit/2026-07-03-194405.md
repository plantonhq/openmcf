✅ **In parity:**

- The entire deploy shape: parent-ID parsing, XOR address sources (multi-prefix + IPAM),
  service endpoints/policies, repeated delegations, both policy enums, sharing scope, all
  three attach associations, dependency edges, and the full five-field stack-output contract
  (conformance-guarded).

⚠️ **Divergences (undocumented):**

- **Optional-bool proto defaults not encoded in the Pulumi module.** `spec.proto` declares
  `private_link_service_network_policies_enabled` and `default_outbound_access_enabled` as
  `optional bool` with `(options.default) = "true"`. Terraform encodes the default at module
  level (`optional(bool, true)` in `variables.tf`); Pulumi calls the generated getters, which
  return **false** when the field is unset. On the primary paths the divergence is masked:
  the CLI manifest loader (`internal/manifest/load_manifest.go`) runs
  `protodefaults.ApplyDefaults`, and platform-created resources have defaults materialized at
  creation, so both engines receive explicit values. But on paths that bypass the loader —
  `planton pulumi up --stack-input <file>` (the file is handed to the module verbatim,
  `pkg/iac/pulumi/pulumistack/run.go`) or any direct module invocation — a manifest omitting
  these bools deploys **false/false via Pulumi and true/true via Terraform**. `false` for
  `default_outbound_access_enabled` silently removes implicit internet egress for the subnet's
  workloads. This is the exact defect class fixed for `Auth0Client` `jwt_configuration.alg`
  (see `pkg/iac/MODULE_PARITY.md`): the module-level default must be encoded in BOTH engines.
  Impact: outcome-changing only on the loader-bypassing paths; identical on orchestrated/CLI
  manifest paths. Fix: in `iac/pulumi/module/main.go`, nil-check each pointer and default to
  `true` (mirroring `optional(bool, true)`), or document a `PARITY-EXCEPTION:` in both modules
  if intentional (it does not appear intentional).

**Effect on score:** caps Categories 4 & 5 at Partial (−2.00 on Pulumi, −0.40 on Terraform)
and is listed under Critical Gaps.

## Critical Gaps

1. **Undocumented Pulumi↔Terraform divergence: optional-bool defaults (parity gate ⚠️)**
   - **Why it blocks:** On `planton pulumi up --stack-input` or direct module runs, Pulumi
     deploys `private_link_service_network_policies_enabled=false` and
     `default_outbound_access_enabled=false` where Terraform deploys `true`/`true` — the same
     input yields different subnets depending on engine, and false default-outbound silently
     removes workload egress.
   - **What to do:** Nil-check the two pointers in the Pulumi module and default to `true`
     (both engines then encode the proto `(options.default)` at module level). Re-verify with
     `go build -o /dev/null ./.../iac/pulumi` and the conformance test.
   - **File:** `apis/dev/planton/provider/azure/azuresubnet/v1/iac/pulumi/module/main.go`

   - **Why it blocks:** Unknown fields (`resourceGroup`, `vnetId`, `addressPrefix`,

   - **What to do:** Regenerate presets from the current `spec.proto`.

## Category 5b: Cross-Engine IaC Parity (the gate this audit leads with)

Field-by-field sweep of `iac/tf/` vs `iac/pulumi/module/` against
`spec.proto` + `stack_outputs.proto`:

- **Resource surface identical**: `azurerm_mysql_flexible_server` /
  `mysql.FlexibleServer` plus the four child resources (database,
  firewall rule, configuration, the single Entra administrator), one per
  spec entry on both engines. MySQL's mixed parent addressing preserved
  identically: databases/firewall rules/configurations by server name +
  resource group, the Entra administrator by server ID — each matching
  its azurerm resource's own contract.
- **Enum vocabularies exhaustive and identical**: create modes
  (`Default`/`PointInTimeRestore`/`Replica`/`GeoRestore`), HA modes
  (`ZoneRedundant`/`SameZone`), public network access
  (`Enabled`/`Disabled`).
- **Conditional-send behavior identical**: `version` only for fresh
  (DEFAULT) servers (replicas/restores inherit); credentials only when
  non-empty; `replication_role` never at create (day-2 promotion only);
  unspecified create_mode and public_network_access not sent at all
  (Azure derives the network posture); storage dials presence-guarded
  (`auto_grow_enabled` to Azure's MySQL default of TRUE).
- **Identity + CMK identical**: the UserAssigned-only identity block
  renders only when identities are attached; the CMK block forwards the
  geo-backup key + identity pair only when set.
- **Tenant fallback identical**: the Entra administrator's tenant falls
  back to the deploying credential's tenant
  (`data.azurerm_client_config` / `core.GetClientConfig`).
- **Outputs identical**: `server_id`, `server_name`, `fqdn`,
  `administrator_login`, `database_ids` (name-keyed map),
  `replica_capacity` — same keys, same sources.
- **Documented PARITY-EXCEPTION (pre-existing, family-wide)**: the tag
  metadata shape (`resource_kind` casing and the `resource_id` fallback)
  differs between engines; output-neutral and recorded in both modules.

**Verdict: PARITY ✅ — no undocumented divergence.**

- **Schema-level validators mirrored**: `validation.IsUUID` on `name` (spec uuid CEL) and on `principal_id` (documented; left un-CEL'd because it is a ref field — same constraint as above, enforced by ARM with a clear diagnostic).
- **Cross-resource contracts that stay apply-time** (documented): scope and role definition must live inside THIS account; scope must sit at or below one of the definition's assignable scopes; the principal must exist in the directory.

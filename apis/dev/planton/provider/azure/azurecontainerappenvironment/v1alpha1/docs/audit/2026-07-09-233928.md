## Schema Coverage vs azurerm v4.80 (`container_app_environment_resource.go`)

location, resource group, `dapr_application_insights_connection_string`
(sensitive, ForceNew -- write-only in ARM), `log_analytics_workspace_id` (FK),
`logs_destination` (closed enum), `infrastructure_resource_group_name`,
`infrastructure_subnet_id` (FK), `internal_load_balancer_enabled`,
`public_network_access` (closed enum), workload profiles (closed 14-value SKU
enum mirroring `PossibleValuesForWorkloadProfileSku`), `zone_redundancy_enabled`,
`mutual_tls_enabled`, identity (UAI FKs), tags. All six computed attributes
export as stack outputs, plus `environment_name` and `identity_principal_id`.

The environment custom domain (`azurerm_container_app_environment_custom_domain`)
is FOLDED as the optional `custom_domain` message: ARM models it as a patch on
the environment itself (the resource's id IS the environment id -- a singleton),
realized through the association resource on both engines.

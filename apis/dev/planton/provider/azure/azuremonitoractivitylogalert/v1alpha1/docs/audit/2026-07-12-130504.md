## Apply-Time Validator Source-Diff

Read `monitor_activity_log_alert_resource.go` schema + CustomizeDiff:

- **singular/plural ConflictsWith pairs** (level/levels,
  resource_provider/resource_providers, resource_type/resource_types,
  resource_group/resource_groups, resource_id/resource_ids,
  status/statuses, sub_status/sub_statuses): resolved by DESIGN -- the
  spec models plural-only, so the conflict class cannot exist.
- **recommendation_type ConflictsWith category+impact**: front-loaded as
  the `recommendation_type_exclusivity` CEL.
- **resource_health ConflictsWith caller+service_health** and
  **service_health ConflictsWith caller+resource_health**: front-loaded
  as two message CELs.
- **location CustomizeDiff** (only global / westeurope / northeurope /
  eastus2euap): front-loaded as the closed 4-value location enum;
  unspecified maps to "global" on both engines.
- **all vocabularies** (7 categories, 5 levels, 6 recommendation
  categories incl. "Security", 3 impacts, 4 health states, 3 health
  reasons incl. the bare "Unknown" wire value, 5 service-health events
  incl. "Informational"/"Security"): closed enums with per-engine wire
  maps mechanically diffed identical; the collision-avoiding proto names
  (REASON_UNKNOWN, EVENT_INFORMATIONAL, EVENT_SECURITY,
  SECURITY_RECOMMENDATION) map to the exact provider strings.
- **enabled Default true**: presence-guarded on both engines so the
  provider default applies identically.
- No spec CEL invents a rule the provider and ARM do not enforce.

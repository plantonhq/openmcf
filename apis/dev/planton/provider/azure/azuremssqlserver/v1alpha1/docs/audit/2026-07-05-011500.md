## Category 5b: Cross-Engine IaC Parity (the gate this audit leads with)

Field-by-field sweep of `iac/tf/` vs `iac/pulumi/module/` against
`spec.proto` + `stack_outputs.proto`:

- **Resource surface identical**: `azurerm_mssql_server` /
  `mssql.Server` plus five satellites — firewall rule, virtual-network
  rule, outbound firewall rule (one per FQDN), the extended-auditing
  policy, and the Defender alert policy — each rendered only when its
  spec block/entries are present, on both engines. The Defender policy
  addresses the server by name + resource group on both engines (that
  resource's own contract); everything else uses the server ID.
- **Enum vocabularies exhaustive and identical**: connection policy
  (`Default`/`Proxy`/`Redirect`), identity types (incl. the
  `SystemAssigned, UserAssigned` compound), Defender states, and the
  five detector types in ARM's Snake_Pascal wire vocabulary
  (`Sql_Injection`, ..., `Unsafe_Action`).
- **Conditional-send behavior identical**: credentials only when
  non-empty (Entra-only servers omit them); unspecified connection
  policy not sent; version/TLS/public-access presence-guarded to their
  documented defaults; empty identity_ids become null/omitted (azurerm
  rejects ids alongside pure SystemAssigned — fixed in-audit on the TF
  side, see below).
- **Tenant fallback identical**: the Entra administrator's tenant falls
  back to the deploying credential's tenant on both engines.
- **Outputs identical**: `server_id`, `server_name`, `fqdn`,
  `administrator_login`, and the conditionally populated
  `identity_principal_id` (only when the identity type includes
  SYSTEM_ASSIGNED).
- **Documented PARITY-EXCEPTION (pre-existing, family-wide)**: the tag
  metadata shape; output-neutral, recorded in both modules.

**Audit-driven fix:** the TF module initially passed `identity_ids = []`
verbatim for a SYSTEM_ASSIGNED identity while the Pulumi module omitted
the field — azurerm rejects the empty list. The TF side now nulls an
empty list, matching Pulumi.

**Verdict: PARITY ✅ — no undocumented divergence.**

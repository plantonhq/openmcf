## Apply-Time Validator Source-Diff

Read `eventhub_namespace_resource.go` Create/Update + CustomizeDiff:

- **Premium-boundary sku migration ForceNew** (CustomizeDiff): documented
  on the sku enum -- a state transition, not CEL-able.
- **minimum_tls_version cannot be unset once set** (CustomizeDiff): moot
  -- the field is a recorded one-value-constant skip (v5 restricts to
  "1.2"; both modules leave the provider default).
- **network_rulesets requires non-Basic sku** (Create AND Update body):
  front-loaded as the `event_hub_network_rules_not_on_basic` message CEL.
- **ruleset public-access must equal the namespace-level dial**
  (Create/Update body): front-loaded as the
  `event_hub_ruleset_public_access_matches_namespace` message CEL
  (default-aware in both directions).
- **Basic downgrade zeroes maximum_throughput_units when auto-inflate is
  off** (Update body, the provider's own workaround): mirrored implicitly
  -- both modules pass the fields through and the provider performs the
  zeroing; documented in both modules.
- **auto-inflate/ceiling pairing**: deliberately NOT a CEL -- the
  provider enforces no schema pairing (verified: no RequiredWith, no
  CustomizeDiff); ARM validates the combination at apply time. Documented
  on the field instead of inventing a rule.
- **Deny-with-no-sources**: the eventhub provider does not front-load the
  check the way its Service Bus counterpart does, but ARM rejects the
  configuration; the spec's `event_hub_deny_requires_admitted_sources`
  CEL front-loads ARM's own contract (the message says so).
- No spec CEL invents a rule the provider and ARM do not enforce.

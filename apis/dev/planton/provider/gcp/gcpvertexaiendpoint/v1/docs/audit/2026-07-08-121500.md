### Protobuf API Definitions — validation quality note

The spec stands at the released 6.50.0 floor: 11 contiguous fields covering
the full modeled surface — ambient-optional `project_id` ref, `location`,
`display_name`, `description`, VPC-peering `network` ref, CMEK
`kms_key_name` ref, `dedicated_endpoint_enabled`, PSC sub-message
(`project_allowlist` + `enable_secure_private_service_connect`), optional
numeric `endpoint_name`, user `labels`, and the BigQuery request/response
logging config. Two message-level CEL rules move the provider's
`ConflictsWith` rejections pre-deploy (network⇔PSC, dedicated⇔PSC); the
`endpoint_name` CEL encodes the API's exact numeric contract (1–10 digits,
no leading zero); `sampling_rate` bounded to (0,1] with a 0 unset sentinel.
Immutability taught precisely: location/network/CMEK/endpoint_name/PSC
enablement ForceNew; display_name/description/labels/logging/allowlist
mutable via updateMask. The deleted-ID reservation caveat (live-verified,
below) is documented on the field. 37-case spec test.

### The name-generation defect — closed with a live-proven determinism contract

The pre-rebuild Pulumi module omitted `Name` on the empty-`endpoint_name`
path and leaned on bridge auto-naming, which synthesizes a non-numeric name
the API rejects — the empty-name path could never have deployed on Pulumi
(the family had zero E2E; consistent with an undetected deploy blocker).
Both engines now derive the numeric ID deterministically from the resource
identity: sha256 of `"{org}/{env}/{name}"`, first 12 hex chars (48 bits),
mapped into [1000000000, 9999999999]. The derivation is byte-identical in
`endpoint_name.go` (Pulumi) and `locals.tf` (Terraform) — independently
recomputed during review, pinned in `endpoint_name_test.go` (three values,
including the E2E identity), and exact in HCL (48-bit values are precise in
cty numbers). The TF module's `random_integer` dependency is gone.

**Live cross-engine proof:** the first live run pinned the strongest
possible evidence — Pulumi created endpoint `1853927074` for the E2E
identity, and Terraform, deriving the ID independently minutes later,
collided on GCP's deleted-ID reservation with 409 ALREADY_EXISTS. The
collision *was* the byte-identical-determinism proof. It also settled the
pre-flight reservation question: **GCP reserves deleted endpoint IDs**
(GET returns 404 while create returns 409), so E2E scenarios carry
run-scoped identities (documented exception to the fixed-name rule — the
endpoint is a leaf, nothing FK-references it) and the reservation trade-off
is documented in the spec and `docs/README.md`.

### Cross-Engine IaC Parity (Critical GATE)

**Parity verdict: PARITY ✅**

- Both engines enable `aiplatform.googleapis.com` (`disable_on_destroy=false`,
  `disable_dependent_services=true`) and gate the endpoint on it.
- Identical labels merge: user labels first, `planton-ai_*` attribution set
  wins on conflict; asserted live by the verifier (`planton-ai_resource`).
- Identical deterministic `name` — always sent on both engines (above).
- **`region` pinned to `location` on both engines** (live-discovered): the
  provider resolves the Vertex AI regional API host from `region`, never
  `location` — without it both engines fail with "Cannot determine region".
  The spec keeps the single honest `location` field; the plumbing detail
  lives in the modules with matching comments.
- Bridged-provider `deletion_policy` (client-side, absent from released
  6.50.0 GA) pinned to `DELETE` on Pulumi with a PARITY comment.
- `enable_secure_private_service_connect`: **GA on the released 6.x line**
  (verified against the installed 6.50.0 provider schema, which carries it
  as optional) — but the provider's v7 upgrade guide removes it from GA.
  Recorded as a PARITY/UPGRADE NOTE in `main.tf` + `provider.tf`: the
  catalog-wide major bump must drop the field or move to google-beta.
- Outputs resolved from the created resource on both engines with identical
  keys and raw-attribute value semantics: `endpoint_id` (full path),
  `endpoint_name` (numeric), `display_name`, `create_time`,
  `dedicated_endpoint_dns` (bare hostname, no scheme — comment and
  conformance fixture corrected to match the API).

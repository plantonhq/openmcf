**Legend:** ✅ MATCH | ⚠️ DIVERGES | 🔵 EXCEPTION

**Divergence found and fixed:**

- **Labels** — the Terraform module emitted a completely different label scheme
  from Pulumi: unprefixed keys (`resource`, `resource_id`, `resource_kind`,
  `organization`, `environment`) with `resource_kind = "gcp_dns_zone"` and a
  `resource_id` that fell back to `metadata.name`, while the Pulumi module emits the
  canonical `gcplabelkeys` set (`planton-ai_resource`, `planton-ai_name`,
  `planton-ai_kind = "gcpdnszone"`, `planton-ai_id`, `planton-ai_organization`,
  `planton-ai_environment`). Both **keys AND the kind value** differed — the two
  engines would have stamped different labels on the same managed zone. **Fix:**
  aligned `iac/tf/locals.tf` to the Pulumi `planton-ai_*` scheme (name=metadata.name,
  id only when set, kind `gcpdnszone`, spec.labels still merged with the same
  spec-overrides-platform precedence). `tofu validate` passes.

✅ **Confirmed intentional (not a defect):** `zone_id` is the numeric
`managed_zone_id` on **both** engines.

**Effect on score:** none after fix (labels now identical).

## Fixed During This Audit

Two non-parity gaps were found and fixed in-session (both would have deducted from the
score; neither affects deployed behavior):

**Post-audit addendum (same session):** a cross-kind parity sweep found the Pulumi
module's two `projects.Service` resources lacked `DisableOnDestroy: false` while the
Terraform module sets `disable_on_destroy = false` — the Pulumi default (true) would
disable the shared APIs project-wide on destroy. Fixed in
`iac/pulumi/module/connection.go`; both engines now leave API enablement in place on
teardown. Parity verdict remains **PARITY ✅**.

   required `my-` prefix. Renamed `prod-vpc-psa` → `my-vpc-psa` and `prod-vpc-psa-multi` →
   `my-vpc-psa-multi`.
   - **Files:** `presets/01-private-services-access.yaml`, `presets/02-multi-range-growth.yaml`

2. **Research doc missing the deployment-methods comparison** — `docs/README.md` (4.2 KB)
   lacked the required comparison of deployment approaches. Added a gcloud / Console / raw
   Terraform / Planton-composition comparison (including the gcloud upsert behavior that
   explains the "Cannot modify allocated ranges" API wrinkle), an IAM/API-prerequisites
   section, and an operator failure-mode section. The doc is now 8.4 KB with all four
   content-quality checks satisfied.

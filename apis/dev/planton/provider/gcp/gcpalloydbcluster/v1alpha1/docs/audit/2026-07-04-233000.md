### 5b. Cross-Engine IaC Parity (Critical GATE)

**Parity verdict: PARITY ✅ (after fix)**

Compared Pulumi (`iac/pulumi/module/`) and Terraform (`iac/tf/`) field-by-field
against the proto contract. Neither engine privileged.

| Dimension | Pulumi | Terraform | Verdict |
|-----------|--------|-----------|---------|
| Project fallback | omit `Project` when empty | empty → null → provider default | ✅ MATCH |
| API enablement | `alloydb.googleapis.com`, dep=true, destroy=false | same | ✅ MATCH |
| Labels (keys + values) | `gcplabelkeys` (`planton-ai_*`), kind `gcpalloydbcluster` | **was `planton-resource*` → fixed to `planton-ai_*`** | ✅ MATCH (fixed) |
| cluster fields (name/location/network/psc/type/secondary/allocated_ip/db_version/display/subscription/annotations/skip_await) | all honored | all honored | ✅ MATCH |
| initial_user (password/user) | set | set | ✅ MATCH |
| automated_backup_policy (enabled/window/location/retention/schedule/CMEK) | conditional set | always set; provider drops empties via `IsEmptyValue` | ✅ MATCH |
| continuous_backup_config.enabled | `BoolPtr(enabled)` (sent) | `enabled = value` (sent; no IsEmptyValue guard) | ✅ MATCH |
| kms_key_name / maintenance_window | set | set | ✅ MATCH |
| primary_instance (machine/availability/flags/display/query_insights/connectors/ssl) | conditional set | always set; provider drops empties | ✅ MATCH |
| Dependency ordering | cluster→api, instance→cluster | instance→[cluster, api] | ✅ MATCH |
| Stack outputs → proto | 6/6 fields | 6/6 fields | ✅ MATCH |

**Legend:** ✅ MATCH | ⚠️ DIVERGES | 🔵 EXCEPTION

**Divergence found and fixed:**

- **Labels** — the Terraform module emitted the legacy `planton-resource`,
  `planton-resource-name`, `planton-resource-kind`, `planton-organization`,
  `planton-environment`, `planton-resource-id` keys, while the Pulumi module
  emits the canonical `gcplabelkeys` set (`planton-ai_resource`, `planton-ai_name`,
  `planton-ai_kind`, `planton-ai_organization`, `planton-ai_environment`,
  `planton-ai_id`). Two engines would have stamped **different label keys** on the
  same cluster. **Fix:** aligned `iac/tf/locals.tf` to the `planton-ai_*` scheme
  (matching Pulumi and the instance/cloudrunjob TF modules). `tofu validate` passes.

**Note on the "conditional vs always-set" pattern:** the released google provider
drops empty ints/bools/strings from the API payload via `tpgresource.IsEmptyValue`,
so Pulumi's "set-only-when-non-empty" is behaviorally identical to Terraform's
"always-set". Verified against `resource_alloydb_cluster.go` /
`resource_alloydb_instance.go` in the released provider. Not a divergence.

**Effect on score:** none after fix (labels now identical).

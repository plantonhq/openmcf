### 3. Protobuf API Definitions — validation quality note

The YARN `scale_up_factor` / `scale_down_factor` fields are `optional double` with `required = true`: explicit presence so an explicitly-set `0.0` (a legitimate API value — `0.0` scale-down disables shrinking) is expressible while the field itself stays mandatory. The secondary-worker `max_gte_min_instances` CEL rejects a floor without a ceiling (`min_instances > 0` with `max_instances == 0`). Both are exercised by the 44-case spec test (including "reject an unset scale_up_factor", "accept an explicit 0.0 scale_down_factor", and "reject secondary_worker_config with a floor but no ceiling").

## Parity Verdict (lead finding — `--parity` run)

**PARITY ✅ — zero PARITY-EXCEPTIONs.**

Both engines were walked field-by-field across the full spec surface:

- **Identity/core**: name (spec.cluster_name falling back to metadata.name — identical fallback in `locals.tf` and `locals.go`), location, description (empty → omitted both), node_locations (empty → omitted both), deletion_protection (spec default true, forwarded verbatim both).
- **Labels**: both engines merge user `resource_labels` BENEATH the platform `planton-ai_*` attribution labels (user labels can never clobber attribution). One parity defect found and fixed during this audit cycle: the Pulumi module originally ignored `spec.resource_labels` entirely while Terraform merged them — both now share the identical merge order.
- **Networking**: `networking_mode=VPC_NATIVE` hardcoded both; `ip_allocation_policy` emitted unconditionally (empty block = GKE-managed ranges) with identical empty-string→omit translation for range names/CIDRs; stack_type default IPV4 both; additional pod ranges and overprovision toggle gated identically.
- **Default node pool**: `remove_default_node_pool=true` + `initial_node_count=1` on Standard; both fields omitted on Autopilot — identical branch in both engines.
- **Autopilot**: `enable_autopilot` and `allow_net_admin` emitted only when true, both engines; the conflict set is enforced upstream by spec CEL, so neither engine carries divergent guard logic.
- **Private cluster / MAN / endpoints / maintenance / NAP / VPA / HPA / WI / shielded nodes / CMEK / BinAuthz / posture / confidential nodes / anonymous auth / identity service / logging / monitoring / notifications / cost / usage export / addons / fleet**: block-by-block identical presence-gating and empty-value translation. The Calico network-policy pair (enforcement block + addon toggle) follows the single spec toggle in both engines and is suppressed on Autopilot in both.
- **Release channel**: spec `NONE` → provider `UNSPECIFIED` mapped identically (comment in both modules).
- **Workload Identity pool**: `PROJECT.svc.id.goog` computed from the effective project with the ambient-project fallback via `google_client_config` (TF) / `organizations.GetClientConfig` (Pulumi).
- **Outputs (8/8)**: identical keys and identical value sources; `location` deliberately emits the plain spec value on both engines. `validate-outputs` dry-runs green against BOTH module dirs with full population.

Behaviorally inert differences (not exceptions): Terraform sends explicit `false` for zero-value top-level booleans where Pulumi omits them — both resolve to the provider defaults, verified against the released schema.

## Detailed Findings

### 1–2. Registry and Structure

✅ Enum 636 (data sub-band) with `prerequisites:
[GcpServiceConnectionPolicy]` — the PSC-first connectivity prerequisite
that makes the instance composable and live-testable. Full anatomy
including `e2e/` (scenario + consumer-scoped VPC/subnetwork prerequisites).

### 3. Protobuf API Definitions

✅ Spec at the released 6.50.0 floor. Depth added by the rebuild: user
`labels`, `cross_instance_replication_config` (PRIMARY/SECONDARY DR with
three coherence CEL rules), `gcs_source` XOR `managed_backup_source`
seeding (mutual-exclusion CEL + gs:// URI item CEL). Defects fixed:

- **FK format (live-blocking class):** `psc_auto_connections[].network`
  repointed `network_self_link` → `network_id` — the Service Connectivity
  API requires the relative resource path and rejects https:// self-links.
- **Destroy parity:** `deletion_protection_enabled` remodeled as
  `optional bool` default TRUE, sent explicitly by BOTH engines (the old
  spec's plain bool made TF send explicit FALSE while Pulumi left the
  provider default TRUE — same manifest, different destroy behavior).
- **Ambient contract:** `project_id` no longer `required`; per-entry PSC
  `project_id` optional with ambient resolution (the same-project common
  case), fields renumbered contiguously.

Recorded skips (released-schema-probe verified): `server_ca_mode`/
`server_ca_pool`, `maintenance_version`, `allow_fewer_zones_deployment`
(absent from the pinned Pulumi SDK — modeling it would create a
one-engine field; revisit at the next SDK bump), expanded node types
(CUSTOM_*/STANDARD_LARGE/HIGHMEM_2XLARGE — main-only), `deletion_policy`.
68-case spec test green.

### 4–5. IaC Modules

✅ Converter-contract `variables.tf` (plain-string refs — the stale
`object({value})` shape is gone; `project_id` optional matching the
ambient contract); `planton-ai_*` labels with user labels merged beneath
(identical order both engines — the legacy unprefixed TF keys are gone);
Memorystore + Network Connectivity API enablement both engines; canonical
Pulumi.yaml; `~> 6.0`. The ambient endpoint-project lookup is gated
(`count = needs ? 1 : 0` / only-when-needed GetClientConfig) so offline
plans stay offline.
